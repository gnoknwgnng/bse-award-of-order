# ntfy.sh Topics Reference

Set the `NTFY_TOPIC_PREFIX` repo secret to your own unique value. Topics below assume that secret is `YOUR-PREFIX` — substitute your real prefix.

Subscribe to any of these in the ntfy app/website to get alerts for just that subcategory.
